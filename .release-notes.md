## Cherry Studio v1.7.17-preview

Based on upstream v1.7.17 + custom patches for AnimaTool MCP integration.

### Features
- **Per-assistant MCP tool image toggle**: Control whether MCP tool-generated images are sent to the model, per assistant

### Fixes
- **Gemini multimodal**: Convert MCP tool results to AI SDK media format for Gemini providers
- **OpenAI-compatible**: Strip base64 image data from tool results sent to text-only providers
- **Memory bloat (v2)**: Strip base64 image data from ToolBlock **in-place** (fixed Zod safeParse clone issue from v1.7.16-preview2)
- **IPC over-serialization**: Exclude messages/messageBlocks slices from Redux-to-main IPC sync

### Performance
- Eliminates periodic 200-500ms main thread blocking caused by serializing large Redux state every 100ms
- Reduces JS Heap growth from 1GB+ to normal levels after multiple image generations
- UI responsiveness improved dramatically (100x+ improvement reported in testing)
